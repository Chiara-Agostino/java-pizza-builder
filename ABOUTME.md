 
## Project Description:   
     
    This program is a pizza-building application made using Java Swing and 2D graphics. The user can choose a topping from the drop-down menu and place it anywhere they want on the pizza. Once they are done making the pizza, they can clear it using the Clear Pizza button, which removes all the toppings. There is also a button called "Random Pizza" which generates a pizza with 18 toppings placed randomly. The pizza is drawn on a panel using Java graphics methods. The pizza itself includes the crust, sauce, and cheese, and the toppings are all drawn using shapes. These shapes include but are not limited to ovals, rectangles, and arcs.
     
## Features:

     - Choose between pepperoni, mushrooms, and olives.
     - Add toppings by clicking directly on the pizza.
     - Clear all toppings to start over.
     - Generate a pizza with randomly selected and positioned toppings.

## Technologies used:

    - Java: Application logic and object-oriented programming
    - Java Swing: Graphical user interface
    - Java AWT: Custom 2D graphics and drawing
    - Event Listeners: Handling mouse clicks and button interactions
    - ArrayList: Managing pizza toppings     

## What I Learned:

    Through this project, I gained experience developing graphical user interfaces with Java Swing, using event listeners to handle user interactions, and drawing custom graphics with Java AWT. I also practiced object-oriented programming by organizing the application into classes and managing toppings using an ArrayList.
